Integrating SwingUI via CDN

Follow these simple steps to use SwingUI in your project without installation.


Step 1: Add Tailwind and SwingUI CDN

Include the Tailwind CSS CDN and SwingUI plugin in the `` section of your HTML file: 


<link href="https://cdn.jsdelivr.net/npm/tailwindcss@2.2.19/dist/tailwind.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/daisyui@3.0.6/dist/full.js"></script>

Step 2: Use SwingUI Components

You can now use SwingUI components inside your HTML: 

<button class="btn btn-primary">Click Me</button>

Step 3: Customize the Theme (Optional)

SwingUI provides multiple themes. To apply a theme, use the `data-theme` attribute: 

<html data-theme="dark">

🎉 That's it! You have successfully integrated SwingUI using the CDN.
